# 🎓 AI Exam Proctor Detection System

## 📌 Project Overview

The **AI Exam Proctor Detection System** is a web-based application designed to monitor students during online examinations and detect potential malpractice using AI techniques.

This system helps ensure fair and secure online assessments by analyzing user behavior through real-time monitoring.

---

## 🚀 Features

* 👤 Role-based access (Admin & Student)
* 🎥 Real-time monitoring (camera integration ready)
* 🧠 AI-based malpractice detection (extendable)
* 📊 Dashboard for tracking activities
* ⚡ Fast and responsive UI

---

## 🛠️ Technologies Used

* ⚛️ React (Frontend)
* ⚡ Vite (Build tool)
* 📘 TypeScript
* 🎨 Tailwind CSS
* 🧩 shadcn-ui components

## 💻 Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone <YOUR_GIT_URL>
```

### 2️⃣ Navigate to project folder

```bash
cd <YOUR_PROJECT_NAME>
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the project

```bash
npm run dev
```
